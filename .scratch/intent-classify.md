## 建議的 intent id 形態

```
data-intent="<screen>.<類名>"          例：home.quick-item
data-intent="<screen>.<類名>.<值>"      需要區分同一控件的不同取值時，例：case-library.filter-chip.policy
```

**規矩**：id 由**類名**長出來，不另起一套名字 —— 這樣原型與讀取器共用一個詞表，
而重命名類名時 id 會跟著動（那就該動，因為它指的東西變了）。
