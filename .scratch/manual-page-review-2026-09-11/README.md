## 怎么判断页面是否“发生了改变”

本次没有选定调整前的截图或固定提交作为视觉基准，**不能承诺像素级未变**。先截当前页面建立基线；有旧截图时，在同一身份、数据、视口下并排比对。

旧网页原型不作为全量恢复目标。项目后续决策已改过草稿、只读、征集、导出及删除规则；有意删除的按钮不能因为旧图存在就补回。每票的“已知现状”用于提示这些差异。

每张从教师端记录三项：

- **外观与操作**：标题、字段、图像、滚动、键盘、弹层、返回、禁用状态。
- **保存与回读**：操作后离开再回来是否一致；本地保存不等于服务端保存；读取失败不等于没有数据。
- **教师可见的沟通结果**：检查发布或提醒操作的反馈、已有家长已读与提交状态、回复及作品的展示。真实家庭送达不作为你的验收项。
