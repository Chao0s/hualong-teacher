# 17: 课程入口、资源案例检索与取档

**What to build（本票交付）：** 教师按课程线索找到正确资源与案例，推荐卡片标题与详情对应，附件可以辨认并打开。

**Blocked by：** None（可立即开始页面审核；写入、回读需 README 中的测试环境与样本就绪）。

**Status：** draft-awaiting-review（拆分待确认；审核尚未执行）

**审核范围：** 仅教师端。家长账号操作和真实收发由外部负责，不作为本票通过前置；教师端已有的家长状态、回复和投稿仍需检查，缺样本交给助手准备或登记。

**拟确认后的执行状态：** ready-for-human-review

**优先级：** P1；P0 优先核对家园沟通，P1 紧随其后，P2 后续逐页扫查。

## 从哪里进入

底部「教研培训」→「课程建设」查看架构和附件；返回→「课程资源」→「课程资源库／课程案例库」→ 点条目→「下载Word详案」；同时点击两处入口页的「推荐资源／推荐案例」。

## 准备什么

可访问资源、案例及互相关联记录各一条，至少一份实际Word附件；选一个无匹配筛选。

## 按顺序操作

1. 查看课程建设的五个范畴、长说明及附件下载反馈。
2. 在课程资源输入词→「搜索」，切资源衣食住行艺分类、案例年级／领域／活动类型筛选。
3. 从列表进详情再点关联资源或案例，核对标题、封面、文字与对象。
4. 点击「下载Word详案」检查实际文件；返回两处推荐区逐点卡片对照标题，空结果换筛选恢复。

## 主要验收内容

- [ ] 搜索筛选有效，列表与详情对象相符，长标题及封面比例正常。
- [ ] 附件打开的是对应文件；仅授权成功或待接入不算下载成功。
- [ ] 推荐卡片不落到缺参数页、第一条默认内容或其他资料。
- [ ] 涉及文字、图片、表格、弹层的检查至少留一份当前画面证据；如无旧版截图，记录“首次建立基线”，不判定与旧版完全一致。
- [ ] 意见、修改结果与人工复查分别落账；页面能打开不等于业务通过。

## 已知现状与边界

教研培训入口、课程资源入口仍有固定推荐；其中推荐跳转未带对象id，需重点核对。课程建设下载只提示预览工程未接入。此票包含7页但属同一查找资料流程，若单轮太长可按课程建设／资源／案例分次记录。

这是代码阅读得出的审核线索，未在微信开发者工具中执行。本票的“希望行为”用于人工验收，不代表已经实现。
