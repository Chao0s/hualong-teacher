# 19: 党建三类内容浏览与附件

**What to build（本票交付）：** 三类党建入口能打开对应内容，图文和文件可读，返回不串类。

**Blocked by：** None（可立即开始页面审核；写入、回读需 README 中的测试环境与样本就绪）。

**Status：** draft-awaiting-review（拆分待确认；审核尚未执行）

**审核范围：** 仅教师端。家长账号操作和真实收发由外部负责，不作为本票通过前置；教师端已有的家长状态、回复和投稿仍需检查，缺样本交给助手准备或登记。

**拟确认后的执行状态：** ready-for-human-review

**优先级：** P2；P0 优先核对家园沟通，P1 紧随其后，P2 后续逐页扫查。

## 从哪里进入

底部「党建管理」→「党建学习／党建活动／品牌建设」各区右侧「全部」→ 点列表条目；党建学习详情「在线预览／下载文件／复制链接」，活动详情「附件下载→下载」。

## 准备什么

学习文件、活动、品牌各一条，包含长文、图片和实际附件。

## 按顺序操作

1. 从首页卡片与「全部」列表两条入口打开同一内容，核对一致。
2. 检查学习文档预览与下载、复制链接反馈；活动图文、现场图及附件；品牌图文。
3. 在较长列表继续下滑，核对更多内容及加载状态，返回当前分类。

## 主要验收内容

- [ ] 卡片、列表、详情对象一致，三类标题无混用。
- [ ] 图文不裁断，附件与复制链接有实际结果，失败可重试。
- [ ] 空列表与加载失败不混淆；不必要求每个条目都有附件或视频。
- [ ] 涉及文字、图片、表格、弹层的检查至少留一份当前画面证据；如无旧版截图，记录“首次建立基线”，不判定与旧版完全一致。
- [ ] 意见、修改结果与人工复查分别落账；页面能打开不等于业务通过。

## 已知现状与边界

这三类已接服务，重点做此前接口检查不能覆盖的图片、文件预览和滚动审核。

这是代码阅读得出的审核线索，未在微信开发者工具中执行。本票的“希望行为”用于人工验收，不代表已经实现。
