# 12: 自定义栏目排版、征集与提醒家长

**What to build（本票交付）：** 教师设计完整栏目、保存回读、确认冻结后发起征集，并准确查看齐备情况和提醒结果。

**Blocked by：** None（可立即开始页面审核；写入、回读需 README 中的测试环境与样本就绪）。

**Status：** reviewing（weapp已核对保存与重开；12C通过，12A真实拖拽及12B键盘选字待人工；名称裁切、对齐显示已修并复查）

**审核范围：** 仅教师端。家长账号操作和真实收发由外部负责，不作为本票通过前置；教师端已有的家长状态、回复和投稿仍需检查，缺样本交给助手准备或登记。

**拟确认后的执行状态：** ready-for-human-review

**优先级：** P0；P0 优先核对家园沟通，P1 紧随其后，P2 后续逐页扫查。

## 从哪里进入

底部「家园社共育」→「成长档案」→「成长册」→「编辑样板」→「＋ 新建栏目」；发布后自动进入栏目投稿；以后从「编辑样板」点已发布栏目名进入。

## 准备什么

专用未锁定测试编册；一份可删除草稿、一份允许发布的测试栏目；未交齐、已交齐及无监护人样本能提供多少记录多少。

## 按顺序操作

1. 填栏目名称、选插入位置，检查初始图片及文字组件；点组件设置内容来源和比例，拖动及右下角缩放。
2. 测试「+ 页／删页／+ 图片／+ 文字」及文字编辑；「保存手稿」退出重进，比对位置、字样、比例。
3. 在专用草稿测试删除；另一栏目点「发布征集」，先取消再确认，检查冻结说明及跳转。
4. 在栏目投稿页切「全部／已交齐／未交齐」；只对一名测试幼儿点「提醒家长」，核对提示中人数与条数。
5. 返回已发布栏目检查版面不能修改；编册未锁定时允许删除整个栏目及已收家庭材料，编册锁定后禁止删除。未启用或无征集槽栏目检查“无齐备判定”。

## 主要验收内容

- [ ] 组件不重叠、不越界、不跨页；拖曳和缩放后保存再开位置一致，键盘和底部抽屉不挡操作。
- [ ] 图片征集比例与画面一致，长文字能编辑并在样张中正确呈现。
- [ ] 发布前确认说明版面冻结；取消不发布；编册未锁定时已发布栏目可删除并清除材料，锁定后置灰。
- [ ] 无齐备判定不当全班完成，零通知不说已通知；只核对教师端返回的提醒结果，家庭实际收到不在本票范围。
- [ ] 涉及文字、图片、表格、弹层的检查至少留一份当前画面证据；如无旧版截图，记录“首次建立基线”，不判定与旧版完全一致。
- [ ] 意见、修改结果与人工复查分别落账；页面能打开不等于业务通过。

## 已知现状与边界

版面回读缺口G96已关闭（旧代码误写G94，G94实际是教师寄语家长可见性）。现在GET widgets返回真实组件、正文、配置和页数；PUT原子保存组件与页数，发布或锁定后只读；原稿读失败时不给保存，不用默认版面代替。
