# 08: 幼儿综合评估保存、明细与雷达图

**What to build（本票交付）：** 同一幼儿评分保存后可继续，个人及班级图表与明细能读懂，未完成状态不冒充完成。

**Blocked by：** None（可立即开始页面审核；写入、回读需 README 中的测试环境与样本就绪）。

**Status：** reviewing（本批个人结果／明细及班级图表用户确认通过；评分保存及已知导出缺口仍按范围跟进）

**审核范围：** 仅教师端。家长账号操作和真实收发由外部负责，不作为本票通过前置；教师端已有的家长状态、回复和投稿仍需检查，缺样本交给助手准备或登记。

**拟确认后的执行状态：** ready-for-human-review

**优先级：** P1；P0 优先核对家园沟通，P1 紧随其后，P2 后续逐页扫查。

## 从哪里进入

底部「家园社共育」→「成长档案」→「教师评价」→「综合评估」→「开始」；另点个人进度条目及「班级评估」，结果页使用「继续评估／返回进度」。

## 准备什么

未评、部分已评、已完成三种样本，优先使用现成完整样本，不要求手填124题才能检查图表。

## 按顺序操作

1. 开始评估→选择幼儿→跨两个领域打分→「保存评估」→ 退出重进核对评分。
2. 打开部分完成与已完成个人记录，在「评估结果／明细」间切换，核对未评标识及五领域图形。
3. 打开「班级评估」，核对完成人数与均分显示、图例位置；测试返回进度及继续评估路径。
4. 点「导出报告」检查选人弹层和实际反馈。

## 主要验收内容

- [ ] 幼儿切换不串分，保存后进度与明细一致；124题与办园质量120题不混用。
- [ ] 雷达图、图例、长题干和滚动区域在模拟器与手机尺寸下完整显示。
- [ ] 页面不输出未经约定的文字性发展分析；导出待接入不能宣称已生成文件。
- [ ] 涉及文字、图片、表格、弹层的检查至少留一份当前画面证据；如无旧版截图，记录“首次建立基线”，不判定与旧版完全一致。
- [ ] 意见、修改结果与人工复查分别落账；页面能打开不等于业务通过。

## 已知现状与边界

导出目前只提示待接入；入口“强弱项报告”文案需与实际只有图表和明细的功能核对。图表渲染未经本次工具实测。
