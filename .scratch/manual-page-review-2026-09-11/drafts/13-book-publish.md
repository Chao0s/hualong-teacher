# 13: 成长册样本、编册锁定与定稿开放

**What to build（本票交付）：** 教师能分清样本与正式内容，理解锁定和定稿的范围，问题幼儿不能被误开放；教师端不能显示真实正本时记录待接入；家长阅读属于外部事项。

**Blocked by：** None（可立即开始页面审核；写入、回读需 README 中的测试环境与样本就绪）。

**Status：** draft-awaiting-review（拆分待确认；审核尚未执行）

**审核范围：** 仅教师端。家长账号操作和真实收发由外部负责，不作为本票通过前置；教师端已有的家长状态、回复和投稿仍需检查，缺样本交给助手准备或登记。

**拟确认后的执行状态：** ready-for-human-review

**优先级：** P0；P0 优先核对家园沟通，P1 紧随其后，P2 后续逐页扫查。

## 从哪里进入

底部「家园社共育」→「成长档案」→「成长册」→「成长册样本」查看翻页；返回→「编辑样板」检查栏目及「锁定编册」；返回成长册→「全班定稿」→「定稿并开放」。

## 准备什么

优先使用已有已锁定编册和待定稿／已定稿／有问题的测试幼儿。需要新建时，先整理本次启用的栏目；只有选择使用10或12新造数据时才依赖对应操作完成，不依赖整张票通过。

## 按顺序操作

1. 在「成长册样本」点击书页及左右箭头、回到封面，检查一次只翻一页、首页末页边界及编辑样板返回。
2. 在「编辑样板」检查栏目勾选、标题及上方预览。核对显示学期是否正确；固定书脊不能关闭或换序。
3. 完成所需编辑后再测「锁定编册」，先取消再在专用编册确认；退出重进查锁定及修改按钮限制。
4. 回「全班定稿」，核对可选、已定稿和有问题幼儿；测试全选、取消、单选；最后仅对专用可定稿幼儿确认，核对成功与失败分别报告。
5. 尝试寻找逐幼儿「成长册预览」按钮；找不到即记录入口缺口，由助手协助临时直达审画面，不能算正常路径通过。

## 主要验收内容

- [ ] 样本、预览、真实定稿有清晰区分；翻页图片、文字、目录无明显重叠或裁断。
- [ ] 栏目进度横向滚动后仍能对应幼儿；锁定与定稿确认说明不可撤销及对象。
- [ ] 问题幼儿不被强行开放，部分失败不说全班成功，重进状态一致。
- [ ] 无法显示正式正本或没有正常入口时业务结果保持待接入／受阻，不能以样张通过替代。
- [ ] 涉及文字、图片、表格、弹层的检查至少留一份当前画面证据；如无旧版截图，记录“首次建立基线”，不判定与旧版完全一致。
- [ ] 意见、修改结果与人工复查分别落账；页面能打开不等于业务通过。
