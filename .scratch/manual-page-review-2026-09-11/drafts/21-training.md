# 21: 教研培训报名、反馈与我的研修

**What to build（本票交付）：** 教师报名与取消后个人记录同步，材料会议入口有效，反馈的审核公开规则明确。

**Blocked by：** None（可立即开始页面审核；写入、回读需 README 中的测试环境与样本就绪）。

**Status：** draft-awaiting-review（拆分待确认；审核尚未执行）

**审核范围：** 仅教师端。家长账号操作和真实收发由外部负责，不作为本票通过前置；教师端已有的家长状态、回复和投稿仍需检查，缺样本交给助手准备或登记。

**拟确认后的执行状态：** ready-for-human-review

**优先级：** P1；P0 优先核对家园沟通，P1 紧随其后，P2 后续逐页扫查。

## 从哪里进入

底部「教研培训」→ 快捷入口「教研培训」→「最新研修／历史研修」点活动→「立即报名」；回培训列表「我的档案」区→「我的研修」。

## 准备什么

未开始可报名、进行中、已结束及撤回的已有活动；一个允许提交测试反馈的样本。

## 按顺序操作

1. 打开最新研修，核对时间、主讲和材料；下载文件、复制会议链接。
2. 「立即报名」后退出重进，再从「我的研修」核对；允许取消时测试取消确认。
3. 输入测试反馈→「提交」，核对不可修改和审核后真名公开的提示。
4. 查看历史／撤回活动及对应我的研修记录，检查按钮按状态禁用且不会误说报名已取消。

## 主要验收内容

- [ ] 活动阶段与个人报名状态分开，报名／取消真实同步。
- [ ] 会议、附件、反馈长文本和底部按钮可用；撤回内容不继续暴露原材料。
- [ ] 反馈提交成功不冒充已公开或可查看审核进度。
- [ ] 涉及文字、图片、表格、弹层的检查至少留一份当前画面证据；如无旧版截图，记录“首次建立基线”，不判定与旧版完全一致。
- [ ] 意见、修改结果与人工复查分别落账；页面能打开不等于业务通过。

## 已知现状与边界

个人研修记录已接真实数据；提交反馈后没有自己那份审核状态查询入口，不能补写不存在的操作步骤。

这是代码阅读得出的审核线索，未在微信开发者工具中执行。本票的“希望行为”用于人工验收，不代表已经实现。
