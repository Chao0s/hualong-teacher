# 15: 首页快捷入口与教师待办处理

**What to build（本票交付）：** 教师从首页到正确任务，接受、反馈并完成后首页待处理数与列表同步。

**Blocked by：** None（可立即开始页面审核；写入、回读需 README 中的测试环境与样本就绪）。

**Status：** draft-awaiting-review（拆分待确认；审核尚未执行）

**审核范围：** 仅教师端。家长账号操作和真实收发由外部负责，不作为本票通过前置；教师端已有的家长状态、回复和投稿仍需检查，缺样本交给助手准备或登记。

**拟确认后的执行状态：** ready-for-human-review

**优先级：** P1；P0 优先核对家园沟通，P1 紧随其后，P2 后续逐页扫查。

## 从哪里进入

底部「首页」→「待办任务」→ 点任务卡片；首页常用入口逐点「教研培训／在园时光／月度评价／课程资源」，推荐课程案例点一张及「全部案例」。

## 准备什么

待接受、已接受、已完成任务各一条，至少一条带附件。

## 按顺序操作

1. 记录首页待处理数量，进入列表点任务，核对名称、任务说明、分工、截止日期和附件。
2. 点「接受任务」，重进核对；填写任务反馈→「完成任务」，先取消再确认测试记录。
3. 返回列表和首页核对状态及待处理数量；点附件下载看实际文件。
4. 逐个点击常用入口及推荐案例，检查卡片标题与目标详情匹配，返回路径正确。

## 主要验收内容

- [ ] 接受与完成按钮随真实状态改变，失败不报成功，完成后待处理数量减少。
- [ ] 反馈键盘、长说明和附件名不遮挡操作，空列表／加载失败有合适提示。
- [ ] 所有首页快捷入口可达且对象正确，推荐案例不能打开其他内容。
- [ ] 涉及文字、图片、表格、弹层的检查至少留一份当前画面证据；如无旧版截图，记录“首次建立基线”，不判定与旧版完全一致。
- [ ] 意见、修改结果与人工复查分别落账；页面能打开不等于业务通过。

## 已知现状与边界

首页待办计数已接服务；推荐案例仍含固定展示数据，需要核对所指详情。质量评估徽标在16单独对照。
