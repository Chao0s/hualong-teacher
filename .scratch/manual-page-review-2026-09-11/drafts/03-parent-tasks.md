# 03: 亲子任务草稿、发布与家长完成情况

**What to build（本票交付）：** 教师发布明确的任务要求，重进可核对开始与截止日期、家长已读及完成状态，并正确结束任务。

**Blocked by：** None（可立即开始页面审核；写入、回读需 README 中的测试环境与样本就绪）。

**Status：** draft-awaiting-review（拆分待确认；审核尚未执行）

**审核范围：** 仅教师端。家长账号操作和真实收发由外部负责，不作为本票通过前置；教师端已有的家长状态、回复和投稿仍需检查，缺样本交给助手准备或登记。

**拟确认后的执行状态：** ready-for-human-review

**优先级：** P0；P0 优先核对家园沟通，P1 紧随其后，P2 后续逐页扫查。

## 从哪里进入

底部「家园社共育」→「亲子任务」→「发布新任务」；返回后在「历史任务」点草稿继续编辑，点已发布任务进入「任务详情」。

## 准备什么

日常任务、社区任务各一条测试记录；准备未开始、进行中、已结束的已有记录，缺数据则记录待补。

## 按顺序操作

1. 选择「日常任务／社区任务」→ 填任务名称、背景、详情、开始日期与截止日期→「存为草稿」。
2. 从历史任务重开草稿核对回填，再「发布给家长」；测试「不设截止」及截止早于开始的提示。
3. 打开已发布任务，核对正文、时间、当前班级人数、已读与完成情况三列表格。
4. 用未开始／进行中／已结束样本核对状态和操作；在独立测试任务点「结束任务」，先取消再确认，重进核对不能重新开启。

## 主要验收内容

- [ ] 草稿与已发布任务入口不同，草稿内容回填完整，发布结果重进仍在。
- [ ] 类型、日期、正文与发布前一致；已读与已完成不能混为一项。
- [ ] 家长提交后教师状态应刷新；未读取到状态不冒充未读或已完成。
- [ ] 长任务说明、日期与多行幼儿表格可完整阅读。
- [ ] 涉及文字、图片、表格、弹层的检查至少留一份当前画面证据；如无旧版截图，记录“首次建立基线”，不判定与旧版完全一致。
- [ ] 意见、修改结果与人工复查分别落账；页面能打开不等于业务通过。

## 已知现状与边界

当前详情页只有提交状态，没有逐笔家长作品预览入口，代码记录G70缺口。不能写“点幼儿查看作品”作为现有步骤；需要阅读作品时另记需求。本票只检查教师可见状态；实际家庭收发属于外部事项。

这是代码阅读得出的审核线索，未在微信开发者工具中执行。本票的“希望行为”用于人工验收，不代表已经实现。
