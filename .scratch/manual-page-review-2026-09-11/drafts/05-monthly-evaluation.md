**What to build（本票交付）：** 教师为正确幼儿和月份保存评价及照片，发布后以只读详情回看。

**Blocked by：** None（可立即开始页面审核；写入、回读需 README 中的测试环境与样本就绪）。

**Status：** passed（用户确认本批月度评价无问题；选片、草稿回填、发布、圆点变化及只读回看通过）

**审核范围：** 仅教师端。家长账号操作和真实收发由外部负责，不作为本票通过前置；教师端已有的家长状态、回复和投稿仍需检查，缺样本交给助手准备或登记。

**拟确认后的执行状态：** ready-for-human-review

**优先级：** P0；P0 优先核对家园沟通，P1 紧随其后，P2 后续逐页扫查。

## 从哪里进入

底部「家园社共育」→「成长档案」→「教师评价」→「月度评价」→「添加评价」或点幼儿对应月份圆点；另走底部「首页」→ 常用入口「月度评价」。

## 准备什么

两名幼儿，其中一名有明确标注过他的在园时光照片，另一名无照片；可用已有记录，02不是必做前置。

## 按顺序操作

1. 选择月份与幼儿，填评价内容→「选择照片」；确认相册仅来自当前幼儿关联活动。
2. 选照片→「保存草稿」→ 退出重进，核对文字、幼儿、月份及图片仍一致。
3. 重新进入→「发布给家长」→ 检查确认内容，取消一次后再发布测试记录。
4. 从完成情况圆点回看；再从首页快捷入口进入，检查默认对象不会沿用错误幼儿；切换对象时观察照片是否清空或正确重载。

## 主要验收内容

- [ ] 切换幼儿不串照片，空相册有明确说明；照片预览比例正确。
- [ ] 保存草稿与正式发布含义清楚，发布后只读，进度表状态同步。
- [ ] 键盘弹起、长评语和照片弹层不遮挡关键按钮，首页与模块入口行为一致。
- [ ] 涉及文字、图片、表格、弹层的检查至少留一份当前画面证据；如无旧版截图，记录“首次建立基线”，不判定与旧版完全一致。
- [ ] 意见、修改结果与人工复查分别落账；页面能打开不等于业务通过。
