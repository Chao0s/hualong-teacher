# 06: 学期评价保存及发送入口真实性

**What to build（本票交付）：** 教师能保存并回看本学期评语，清楚知道哪些操作还不能完成，避免误以为已发送家长。

**Blocked by：** None（可立即开始页面审核；写入、回读需 README 中的测试环境与样本就绪）。

**Status：** draft-awaiting-review（拆分待确认；审核尚未执行）

**审核范围：** 仅教师端。家长账号操作和真实收发由外部负责，不作为本票通过前置；教师端已有的家长状态、回复和投稿仍需检查，缺样本交给助手准备或登记。

**拟确认后的执行状态：** ready-for-human-review

**优先级：** P0；P0 优先核对家园沟通，P1 紧随其后，P2 后续逐页扫查。

## 从哪里进入

底部「家园社共育」→「成长档案」→「教师评价」→「学期评价」→ 点某幼儿圆点；返回完成情况→「选择操作」→ 选择幼儿→「导出报告／发给家长」。

## 准备什么

一名未完成、一名已提交学期评价的测试幼儿。

## 按顺序操作

1. 点未完成幼儿圆点，选择评价对象，填写学期综合评语，查看「选择照片」及其限制说明。
2. 「保存学期评价」后重进同一幼儿，核对正文和只读状态；切换幼儿确认无内容残留。
3. 返回「选择操作」分别测试未选择、选择未完成、选择已完成幼儿后「导出报告」「发给家长」的反馈。

## 主要验收内容

- [ ] 姓名、学期、正文匹配，已提交不能改写，完成圆点反映实际保存。
- [ ] 照片不可用时原因清楚，不展示假照片或假保存。
- [ ] “发给家长”未接入时不得判定通信通过；“可导出／可发送”文案不能误导教师。
- [ ] 涉及文字、图片、表格、弹层的检查至少留一份当前画面证据；如无旧版截图，记录“首次建立基线”，不判定与旧版完全一致。
- [ ] 意见、修改结果与人工复查分别落账；页面能打开不等于业务通过。

## 已知现状与边界

学期照片入口目前待接入；导出及发送只提示“已选N名幼儿，…待接入”。弹层却有“已完成·可导出／可发送”文案，需人工确认调整意见。这是现有缺口，不是已经实现的发送功能。

这是代码阅读得出的审核线索，未在微信开发者工具中执行。本票的“希望行为”用于人工验收，不代表已经实现。
