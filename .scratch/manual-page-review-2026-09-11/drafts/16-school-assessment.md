# 16: 办园质量评估与首页徽标回查

**What to build（本票交付）：** 教师完成120题工具中的一段评分后能回读，界面进度与首页徽标一致，佐证限制准确。

**Blocked by：** None（可立即开始页面审核；写入、回读需 README 中的测试环境与样本就绪）。

**Status：** draft-awaiting-review（拆分待确认；审核尚未执行）

**审核范围：** 仅教师端。家长账号操作和真实收发由外部负责，不作为本票通过前置；教师端已有的家长状态、回复和投稿仍需检查，缺样本交给助手准备或登记。

**拟确认后的执行状态：** ready-for-human-review

**优先级：** P2；P0 优先核对家园沟通，P1 紧随其后，P2 后续逐页扫查。

## 从哪里进入

底部「首页」→「质量评估」→ 选择指标及题项→ 打分→「保存」；返回首页核对质量评估徽标。

## 准备什么

一份已分配且未完成的办园质量评估，另备已完成或未分配样本。

## 按顺序操作

1. 切换「全部／未评／低分」，展开指标核对评分锚点。
2. 打普通分与1／5分，检查佐证要求及「添加佐证」反馈；保存一段后退出重进。
3. 回首页对比徽标与实际已评数，再用已完成样本查只读状态。

## 主要验收内容

- [ ] 不同评分的选中效果与说明清楚，长题干可滚动。
- [ ] 保存后分数与进度真实一致，首页不能长期显示旧值或0。
- [ ] 待接入佐证不显示已上传，未分配不冒充空白可评分表。
- [ ] 涉及文字、图片、表格、弹层的检查至少留一份当前画面证据；如无旧版截图，记录“首次建立基线”，不判定与旧版完全一致。
- [ ] 意见、修改结果与人工复查分别落账；页面能打开不等于业务通过。

## 已知现状与边界

首页读取旧本地评分键，评估页已读服务端分数，存在统计不一致风险；当前佐证入口待接入。此工具为120题，与幼儿综合评估124题无关。

这是代码阅读得出的审核线索，未在微信开发者工具中执行。本票的“希望行为”用于人工验收，不代表已经实现。
