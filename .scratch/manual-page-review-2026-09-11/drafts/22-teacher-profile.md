# 22: 个人档案修改申请与证书回看

**What to build（本票交付）：** 教师提交自己的履历及证书修改申请，重进看到真实审核状态，并可读取已批准资料。

**Blocked by：** None（可立即开始页面审核；写入、回读需 README 中的测试环境与样本就绪）。

**Status：** draft-awaiting-review（拆分待确认；审核尚未执行）

**审核范围：** 仅教师端。家长账号操作和真实收发由外部负责，不作为本票通过前置；教师端已有的家长状态、回复和投稿仍需检查，缺样本交给助手准备或登记。

**拟确认后的执行状态：** ready-for-human-review

**优先级：** P2；P0 优先核对家园沟通，P1 紧随其后，P2 后续逐页扫查。

## 从哪里进入

底部「教研培训」→ 快捷入口「教研培训」→「我的档案」区「个人档案」→「基本履历」右侧「编辑」；「资质与荣誉」点「预览／下载」。

## 准备什么

当前教师档案、测试证书文件；已有待审核和被驳回申请优先用于查状态。

## 按顺序操作

1. 打开个人档案，核对姓名班级与当前教师；「编辑」改岗位、职称、学历。
2. 「＋ 新增证书」填类型、等级、名称、上传原文件；删除一行时核对提示说明完整清单含义。
3. 先取消修改检查原档案不变；重新填写后「提交审核」并核对确认内容。
4. 重进查修改申请状态；有已批准证书时预览或下载实际文件，有驳回样本检查理由和重交流程。

## 主要验收内容

- [ ] 本人档案准确，姓名与任教班级不可在此改，表单与键盘不遮挡。
- [ ] 上传失败不带假文件提交，取消不改变原档案，提交后显示申请状态而非立即批准。
- [ ] 已有证书预览下载指向对应文件；不同审核状态对应操作明确。
- [ ] 涉及文字、图片、表格、弹层的检查至少留一份当前画面证据；如无旧版截图，记录“首次建立基线”，不判定与旧版完全一致。
- [ ] 意见、修改结果与人工复查分别落账；页面能打开不等于业务通过。

## 已知现状与边界

审核批准由管理端完成；没有管理员测试操作时仅该分支记缺样本，不阻碍教师提交路径检查。

这是代码阅读得出的审核线索，未在微信开发者工具中执行。本票的“希望行为”用于人工验收，不代表已经实现。
