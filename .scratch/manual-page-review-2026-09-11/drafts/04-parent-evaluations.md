# 04: 发起家长评价与阅读家长回复

**What to build（本票交付）：** 教师给正确期间发出评价说明，并从进度页读到对应幼儿家长已提交的正文。

**Blocked by：** None（可立即开始页面审核；写入、回读需 README 中的测试环境与样本就绪）。

**Status：** draft-awaiting-review（拆分待确认；审核尚未执行）

**审核范围：** 仅教师端。家长账号操作和真实收发由外部负责，不作为本票通过前置；教师端已有的家长状态、回复和投稿仍需检查，缺样本交给助手准备或登记。

**拟确认后的执行状态：** ready-for-human-review

**优先级：** P0；P0 优先核对家园沟通，P1 紧随其后，P2 后续逐页扫查。

## 从哪里进入

底部「家园社共育」→「成长档案」→「发布家长评价」（页标题「发布家长测评」）→ 下方「过往进度」点某一期→「测评进度」→ 点幼儿所在行。

## 准备什么

月度、学期两类评价；未读、已读未交、已提交的测试样本。

## 按顺序操作

1. 切换评价类型，核对自动生成的「评价期间」，填标题、开始日期、截止日期、说明。
2. 点「发布给家长」，返回后从「过往进度」打开对应记录，核对标题、人数及已读／完成状态。
3. 点已提交幼儿行阅读正文并关闭弹层；点未提交幼儿行，检查提示，不应看到家庭草稿。
4. 同期间再次发布，核对页面说明与实际结果：已有记录不覆盖；测试日期不合法及无进行中学期时的反馈。

## 主要验收内容

- [ ] 月度与学期没有串期间、串幼儿，发布新增字段在页面上可理解。
- [ ] 已读与已提交分开显示，正文确属所点幼儿且能完整滚动阅读。
- [ ] 重复发布不会覆盖家长已交内容；失败不显示成功。
- [ ] 涉及文字、图片、表格、弹层的检查至少留一份当前画面证据；如无旧版截图，记录“首次建立基线”，不判定与旧版完全一致。
- [ ] 意见、修改结果与人工复查分别落账；页面能打开不等于业务通过。

## 已知现状与边界

相比早期原型补了期间、标题和日期字段；点击幼儿行取正文是当前真实入口。使用已有家长提交样本核对教师端正文；没有样本时交给助手准备或登记，不要求你去家长端提交。

这是代码阅读得出的审核线索，未在微信开发者工具中执行。本票的“希望行为”用于人工验收，不代表已经实现。
