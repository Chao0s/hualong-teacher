## 4. 这一轮修掉的四个真洞

都不是票面要的，是接线时撞上的。

1. **跨园泄露幼儿照片**（#2）。`PUT /home-school/month-evals` 的 `file_id` 落点**完全没有范围检查**，而读取那一支的判据正是这次写入自己填的两个值 —— **写入即授权**。别园家长上传的幼儿照片可以挂进本班月评再合法取出，逐个试编号就能走遍整张 `db_file`。红线 1 与红线 4。
2. **取档端点绕过详情页**（#3）。修前只问 `owner_object` 在不在一张名单里，不问园所也不问内容状态：已下架的党建学习附件，详情回 404，取档回 200 + 签名 URL，而且新写的 `downloaded` 事件会把这次越权**记成一次合法下载**。
3. **并发两发能把一位教师永久锁死**（#15）。`no_open_s2` 是先查后插、无事务无锁；两条 `s2` 落库后，管理端只批准一条，另一条永远停在 `s2`，而同一条前置从此把这位教师的每一次提交都挡掉。改成部分唯一索引 `uk_tpc_one_pending` + `ON CONFLICT`。
4. **逐行的「提醒家长」给全班发通知**（#27）。`POST /sections/{id}/reminders` 从不读 `child_ids`。本轮把它做成逐行按钮，于是一个既有缺陷变成了对真实监护人行的不可逆写入。

## 5. 四处「绿灯却没在测」——本轮最值得记住的一节

`CLAUDE.md` §7 那句「**绿灯从来不是已经检查过了的证明**」，这一轮又添了四个实例。

### 5.1 一个安全测试停止测试，却仍然全绿

`db/testdata/authz-tests/run.mjs` 的 `call()` 不带 `Idempotency-Key`。#29 给五条端点补上必填幂等键之后，越权组打的三条端点会在 **handler 之前**回 422 —— 而那一组的判据是 `status >= 400`。

于是：**就算有人把 handler 里 `AND b.class_id = $2` 整个删掉，它也照样 PASS。** 已改成每发一个新键。

### 5.2 探针钉了「同一个 id」，钉不出 200 与 201 的分别

#29 要修的正是「取回该回 200，实作回 409」。而回 **201** 带着既有那一行，能骗过「回的是同一个 `compilation_id`」这条断言。

`utils/request.js` 只回 `data`，不surface 状态码。已在**平台桩那一层**记状态码（不动 `utils/request.js`，也不动共用的 `tools/lib/wx-stub.mjs`），桩之上仍是未经修改的发布代码。

### 5.3 探针发全集，于是「按名单发」与「按全班发」写出来的行数一模一样

#27 的提醒扇出。原探针把全部未交齐的幼儿都发出去，两种实作产生**逐字节相同**的结果 —— 结构上就测不出来。已改成**发一个严格子集**，先断言子集真的比全集小，再按子集逐条核对收件人。

### 5.4 断言钉在数据集常数上

`got.files.length === 0` 钉的是今天的数据集，不是一条规则。第一份任务附件出现的那天，一个**正确**的客户端会让它变红。已改成从库里逐任务算出期望值。

**共同的形状**：这四条都是「比对通过了」而不是「这件事是对的」。写断言之前先问一句 —— **把被测的那段代码删掉，这条断言还会绿吗？**

## 6. 会咬人的地方（新增）

### 6.1 `db/spec/screens.tsv` 是手工维护的，却住在生成物目录里

跑完 `check-all.mjs` 照惯例 `git checkout -- db/spec/` 会把它**一起还原**。#27 改 `growth-book-view` 的 `writes` 那一格时踩到过。要么逐个文件还原，要么改完 `screens.tsv` 再确认一次。

### 6.2 缺口编号会撞车，而且撞了三次

两条线同时提交，`db/GAPS.md` 的号段一天之内被抢了三次（G74、G75、G94）。

**取号前重读 `db/GAPS.md`，取当时最大值之上的下一个。** 注意 **G80–G83 是评估族（#31）预留的**，不要占。
本轮登记：G75 G76 G77 G78 G79 G88 G89 G90 G91 G92 G93 G96。

### 6.3 请求头以前到不了 handler

`router.mjs` 的 `dispatch` 构造的 context 没有 `headers` 这一键。所以契约标 `required` 的 `Idempotency-Key`，**五条端点一条都读不到**。#2 的提交端点当初只好拿上传票据顶替，正是因为这个。#29 补上了闸门。

重放记录放**进程内存**，与 `SESSIONS`、上传票据同族；作用域是（**调用者当下的范围**, 路由模板, 键）—— 只钉身份主键的话，换了班之后同一把键会回一份陈旧答案，那是绕过范围判定。

### 6.4 `scan:wiring` 的报告按**运行日期**命名

跨过午夜之后会写出一个新文件（本轮从 `wiring-2026-09-08.*` 变成 `wiring-2026-09-09.*`），旧的那份留在盘上。审计的那一份是 09-08，#1 引的也是它。
