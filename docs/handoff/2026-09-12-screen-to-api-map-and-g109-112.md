## 四、两个阻塞（已核实，不是猜）

### 4.1 渲染：开发者工具没装

教师端 **56 屏今天一屏都渲染不出来**，所以「这一屏长对了没有」谁也答不了。十步闸门、探针、接线扫描**全部查不出渲染问题**（CLAUDE.md §6 最后一行写着「上面全部查不出来」）。

| 查了什么 | 结果 |
|---|---|
| 微信开发者工具 | **没装**（四个常见安装目录 + `LOCALAPPDATA` 都查过） |
| `miniprogram-automator` | **装了**（`package.json`），但**一处都没引用** |
| `tools/web-capture/` | 是给**网页原型**写的；抓的是 `screens/*.html`，与 miniprogram 无关 |

**所以「渲不了」不是被封，是这条路从来没接上。** `appid` 是真的（`wxbda23b3884ae4d69`）、`urlCheck: false`。

**下一步**：装开发者工具（**要人扫码登录一次**，只有人能做），然后用已装的 automator 写一支脚本。**先只做 3 屏样板**（`login`／`home`／`growth-book`）。**挂不进 CI** —— 它要 GUI 与登录。

### 4.2 评价进度自动更新联动：本机没有 PostgreSQL

**三路核实**：本机没有 postgres 服务、PATH 里没有 `psql`、**Docker 里也没有 postgres 镜像**（Docker 只跑 agentmemory 三个容器）。5432 无人监听。

所以「发布月评／提交学期评价／完成综合评估之后，`db_growth_record` 会不会自动重算」**在本机验不了**。

**但 Docker 在跑 —— 这是路**：`docker run postgres:16`，灌 `db/01_schema.sql` 与 `db/02_seed.sql`，起 `db/testdata/server/server.mjs`（3860），再追写入到汇总的路径。**朝湃那份交接件写明「不要直接改汇总状态假装解决」** —— 这句照办。
