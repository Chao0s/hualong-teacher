# 已发布新增栏目删除：决策核对与修复

用户明确：教师新建的栏目允许删除，即使已经收集家庭材料。

## 文档依据及错误来源

- 后端 `docs/ADR-0013-growth-book-composition-manifest.md` §0规定以F19／F20为准。
- 后端 `DECISIONS.md` F19第六条已经明确：编册e1时，d1草稿／d2已发布均可整栏删除；删除家庭投稿、检查与引用并修复其他栏目锚点；e2后拒绝。
- 教师 `docs/backend spec files/05 home-school-spec.md` 的 `section_delete_rule` 同样已明确允许删除。
- 旧接口、动作登记及教师端按钮仍限制d1。助手此前用旧接口推翻F19，是错误判断；`decision.md`已标明原裁定作废，保留追溯。

发布冻结的是现有版面的修改，整栏删除受编册锁定状态控制。园所栏目、固定正文及已锁定编册不在本次放开范围。

## 实现

- 同一个DELETE端点允许d1／d2，按班级及园所内联校验，锁定编册返回409，不存在／跨班／跨园返回404。
- 同事务删除目标组件、全部q1／q2家庭投稿、内容检查和文件引用；共享文件本体保留。
- 直接后继继承被删栏目的插入位置；间接后继仍依附最近存活栏目。遇到历史循环／缺失上游锚点，422且零写入。
- 移除编册启用列表中的被删栏目，递增revision，避免旧页面按旧选择锁定。
- “栏目投稿”页显示可用的“删除栏目”按钮及材料清理说明；避免重复点击。失败留在原页，检测到编册已锁定时置灰。
- 已更新ADR摘要、接口契约v0.42、动作登记、覆盖账本、Swagger人话与屏幕调用登记。无新增端点或数据库迁移。
